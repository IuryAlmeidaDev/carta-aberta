---

## 📌 Sobre o Projeto

Desenvolvido com **HTML5, CSS3 e JavaScript puro**, o projeto combina uma carta digital imersiva com reprodução de áudio em segundo plano e galeria de fotos dinâmicas, criando uma experiência afetiva e interativa.

## 🚀 Funcionalidades

- 🎵 **Trilha Sonora Integrada:** Autoplay e controle de reprodução de áudio.
- 🖼️ **Galeria de Imagens Responsiva:** Apresentação fluida de memórias e momentos marcantes.
- ✨ **Transições e Efeitos Visuais:** Animações CSS com visual moderno e responsivo.

## ⚙️ Como Executar Localmente

Abra o arquivo `index.html` em qualquer navegador moderno:

```bash
git clone https://github.com/IuryAlmeidaDev/carta-aberta.git
cd carta-aberta
start index.html
```
